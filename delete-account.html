1. 계정 삭제 요청 방법

업무캘린더 계정과 계정에 연결된 데이터의 삭제를 요청하려면 아래 절차를 따라 주세요.

계정 삭제 요청 이메일

djnhmilk@daum.net
  1. 위 이메일 주소로 제목을 “업무캘린더 계정 삭제 요청”이라고 작성하여 보냅니다.
  2. 요청 이메일에 가입 시 사용한 이름, 휴대전화 번호, 소속 부서 등 계정을 식별할 수 있는 정보를 기재합니다.
  3. 관리자가 계정 소유 여부와 삭제 요청 내용을 확인합니다.
  4. 확인이 완료되면 해당 계정과 아래에 명시된 관련 데이터를 삭제합니다.
  5. 삭제 처리가 완료되면 요청에 사용한 이메일로 처리 결과를 안내합니다.

중요: 앱의 관리자 화면에서 사용자를 “사용 안 함”으로 바꾸는 것은 로그인을 차단하는 비활성화 처리이며 계정 삭제가 아닙니다. 계정과 관련 데이터의 삭제를 원할 경우 반드시 위 절차에 따라 별도로 요청해 주세요.

개인정보 보호책임자: 손재익 팀장 · 연락처: 041-350-8600

2. 삭제되는 데이터

관리자가 계정 삭제 요청과 계정 소유 여부를 확인한 후, 업무캘린더 서버에서 해당 사용자 계정에 직접 연결된 다음 데이터를 삭제 처리합니다. 삭제 처리된 데이터는 추가로 보관하지 않습니다.

  • 사용자 계정 및 프로필 정보 사용자 ID, 이름, 휴대전화 번호, 소속 부서, 신청일 및 승인일
  • 계정 상태 및 사용 설정 활성 상태, 관리자 여부, 알림 수신 설정, 태블릿 사용 유형
  • 기기 알림 토큰 사용자 ID에 연결된 기기 푸시 알림 토큰 및 플랫폼 정보
  • 개인 알림 이용 정보 사용자 ID에 연결된 개인 알림 수신 설정 및 공지사항 읽음 여부 기록

업무 일정 기록에 관한 안내

사용자가 작성하거나 수정한 공유 업무 일정은 조직의 업무 연속성과 공동 업무 기록 유지를 위해 계정 삭제 후에도 유지될 수 있습니다. 해당 일정에 포함된 작성자·수정자 표시 정보 역시 업무 기록의 일부로 남을 수 있으며, 추가 보관 기간은 해당 업무 일정이 삭제될 때까지입니다.

3. 삭제 이후 보관되는 데이터 및 추가 보관 기간

계정 삭제 요청이 정상적으로 처리된 후 데이터별 처리 방식과 추가 보관 기간은 다음과 같습니다.

데이터 유형 계정 삭제 시 처리 추가 보관 기간
사용자 계정 및 프로필 정보 삭제 보관하지 않음
이름, 휴대전화번호 등 계정과 연결된 개인정보 삭제 보관하지 않음
기기 알림 토큰 및 개인 알림 수신·읽음 정보 삭제 보관하지 않음
공유 업무 일정 유지될 수 있음 해당 업무 일정이 삭제될 때까지
일정의 작성자·수정자 표시 정보 업무 기록의 일부로 유지될 수 있음 해당 업무 일정이 삭제될 때까지

공유 업무 일정과 그 작성자·수정자 표시 정보는 개인 계정 정보와 구분되는 공동 업무 기록입니다. 그 밖에 위 표에서 삭제 대상으로 명시한 계정 관련 데이터는 삭제 처리 후 추가로 보관하지 않습니다.
